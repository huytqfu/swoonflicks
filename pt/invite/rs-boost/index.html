Código de convite do RS Boost (afiliados da ReelShort)

Vai se cadastrar no RS Boost, o programa de afiliados da ReelShort para criadores? O formulário tem um campo para o código de convite. Enviamos o nosso código por e-mail a quem pede, junto com o link de cadastro e um checklist curto. Um único e-mail, sem newsletter.

Só a pedido

Receba o código de convite do RS Boost por e-mail

Enviamos o código pessoalmente, a quem pede. Digite o e-mail que você vai usar no RS Boost e ele chega em um minuto, com o link de cadastro e um checklist curto.

Um único e-mail com o código. Sem newsletter, sem cobranças.

Este é o nosso código de indicação. Se você se cadastrar com ele, a ReelShort pode nos dar uma comissão melhor. Para você não custa nada e não muda o que você ganha.

Onde colar o código

  1. Abra a página de cadastro do RS Boost em cps.reelshort.com.
  2. Preencha os dados da conta que o formulário pede.
  3. Cole o código no campo do código de convite.
  4. Conclua o cadastro, entre na conta e crie seus links de divulgação.

Considere o código permanente: talvez não seja possível trocá-lo depois do cadastro.

O que é o RS Boost

O RS Boost é o programa da própria ReelShort para quem divulga os seus dramas. Você compartilha dramas da ReelShort com um link ou código do seu painel e recebe por venda quando seus espectadores pagam no app.

Por enquanto o programa e o painel estão em inglês.

Não é um código para espectadores

O código do RS Boost é para criadores. Ele não libera episódios nem dá moedas. O app da ReelShort tem outro campo de convite para espectadores.

Perguntas

O código de convite do RS Boost é grátis?

Sim. Códigos de convite são grátis. Não pague ninguém por um.

Por que vocês enviam o código por e-mail em vez de mostrar?

Compartilhamos pessoalmente com quem vai mesmo se cadastrar, para que chegue junto com o link de cadastro e o checklist em um só lugar. Continua grátis e enviamos um único e-mail.

Quanto tempo o e-mail leva para chegar?

Normalmente menos de um minuto. Se não aparecer em alguns minutos, veja o spam ou promoções, ou escreva para partner@swoonflicks.com.

Posso trocar o código depois do cadastro?

Melhor considerar que não. Escolha o código antes de concluir o cadastro.

Este código dá moedas grátis na ReelShort?

Não. É um código de cadastro para criadores, não para espectadores.

A DramaCPS tem código de convite?

Não. Na DramaCPS você se cadastra direto, sem código.
